Zero-Cloud Verification

Enterprise Privacy & Data Flow Architecture

Designed so company knowledge can remain inside the customer's infrastructure by default. The cloud control plane manages licensing and agent tokens, but never receives raw company knowledge.

CUSTOMER INFRASTRUCTURE (Private Agent)
  • Document Storage Customer On-Premise / VPC
  • Meeting Audio & Transcripts Local Faster-Whisper
  • Vector Database & Chunks Local pgvector / SQLite
  • AI Inference & RAG Local LLM / Ollama
  • SOP Generation & Versioning Private Agent
  • Data Egress Policy Mode PRIVATE_ONLY
RANKPILOT CONTROL PLANE (Cloud Hosted)
  • Tenant Accounts & Licensing Metadata Only
  • Agent Enrollment & Heartbeat Status & Version Only
  • Raw Company Documents NEVER STORED (Blocked)
  • Transcripts & Recordings NEVER STORED (Blocked)
  • Employee AI Inquiries NEVER TRANSMITTED
