# SOPIQ Threat Model & Risk Analysis

This threat model outlines the primary attack vectors, potential business impact, technical mitigations implemented in the platform, and remaining residual risks.

| Threat | Impact | Technical Mitigation | Residual Risk |
| :--- | :--- | :--- | :--- |
| **Malicious Employee Attempting Privilege Escalation** | Unauthorized access to executive or confidential financial files. | Server-side RBAC validation on all endpoints; pre-retrieval department filtering based on verified user claims. | Malicious employee with shared executive credentials. Mitigated via multi-factor authentication (MFA). |
| **Cross-Tenant Data Access (Multi-Tenant Leak)** | Company B retrieves Company A's documents, SOPs, or meeting transcripts. | Tenant ID derived exclusively from verified JWT / machine tokens; all queries enforce `WHERE tenant_id = ?`. Verified by automated security test suite. | Vulnerability in underlying database engine. Mitigated by using dedicated schemas or separate databases in enterprise tiers. |
| **Prompt Injection via Uploaded Document** | Malicious document tricks the LLM into ignoring system rules or leaking secrets. | Retrieved context isolated in delimited `<untrusted_company_content>` tags; system instructions prioritize guardrails over retrieved data; trigger phrases suppressed. | Advanced indirect prompt injection modifying interpretation style without breaking guardrails. |
| **Document Containing API Secrets or Credentials** | Sensitive credentials stored in vector database or exposed in AI answers. | `SecretDetector` scans text for AWS, OpenAI, GitHub, Slack, DB passwords, and private keys, redacting them before chunking and embedding. | Obfuscated or bespoke proprietary secret formats not matching regex patterns. |
| **Malicious File Upload & Path Traversal Attack** | Attacker uploads `../../etc/passwd` or executable `.sh` script to compromise agent host. | Strict filename normalization stripping `..`; path containment checks against `STORAGE_PATH`; executable extensions blocked. | Zero-day vulnerability in file parsing libraries (e.g. underlying XML parser). |
| **Compromised Private Agent Machine Token** | Adversary impersonates an agent to send fake heartbeats or intercept jobs. | Immediate agent revocation endpoint (`/api/v1/agents/{id}/revoke`) instantly revokes tokens; heartbeat rejected with 403 Forbidden. | Stolen agent tokens before admin discovers the compromise. Mitigated by short token expiration and mutual TLS. |
| **Outbound Data Exfiltration** | Attacker attempts to configure agent to forward company transcripts to external servers. | `DataEgressGate` in `PRIVATE_ONLY` mode blocks all non-loopback outbound traffic; `HIGHLY_CONFIDENTIAL` data blocked regardless of mode. | Compromise of the host server OS bypassing application-layer egress checks. |
| **Denial of Service via Giant File Upload** | Resource exhaustion causing crash or high CPU during transcription/parsing. | Strict `MAX_FILE_SIZE` (50MB) and `MAX_AUDIO_DURATION` (4 hours) validated before streaming or processing files. | Distributed volumetric DoS against ingress port. Mitigated by network-level rate limiting and reverse proxies. |
| **AI Hallucination of Company Policies** | Employee takes wrong action based on fabricated procedure. | Strict Grounding Guard: model only answers from verified chunks; if similarity is low, responds with standardized uncertainty fallback and creates Knowledge Gap. | Ambiguity in the original source document itself. |
| **Silent Knowledge Conflict** | New meeting changes approval authority, but old SOP is silently overwritten. | `KnowledgeConflictEngine` compares newly extracted statements against existing SOPs and requires explicit human manager review. | Complex nuanced contradictions that do not match detected transition patterns. |
| **Unauthorized AI Tool Execution** | Adversary attempts to use AI to execute shell commands or delete data. | AI agent is completely sandboxed with **zero dangerous system tools** (no shell, no file deletion, no email dispatch). | None in current architecture; future tool additions must use granular consent gates. |
| **Vector Database Snooping** | Attacker attempts direct query against vector embeddings. | Local database stored inside customer VPC; embeddings are mathematical vectors that cannot easily be reversed into raw text. | Physical access to unencrypted disk on compromised server. Mitigated by disk encryption at rest. |
